# 检查列表 App 设计文档

日期：2026-09-10
状态：已确认（待用户审阅）

## 1. 概述

一款**个人单机**手机检查列表应用。用户可以创建检查单（Checklist），每个检查单内可分多个分组（Group），每个分组下有若干检查项（Item）。用户手动点击勾选检查项；当某次检查的所有检查项均勾选完成时，该次检查自动完成。检查单可按周期重复，应用每天记录检查情况，并提供日历回看与统计。

### 核心目标

- 创建/编辑/归档/删除检查单，支持分组与检查项的排序管理
- 按重复周期（一次性 / 每天 / 每周指定星期 / 工作日）生成检查实例
- 快速勾选完成，实时进度反馈
- 按日期回看历史记录，查看连续完成天数与完成率统计

### 非目标（第一版不做）

- 多用户、账号、云同步、团队协作
- 服务端/后端
- 本地推送通知（设置页仅预留开关位）
- 检查项备注、拍照、异常状态等（检查项只有"勾选/未勾选"）
- 内置法定节假日数据（以"工作日=周一至周五 + 手动日期例外"代替）

## 2. 技术栈

| 方面 | 选型 |
|---|---|
| 平台 | iOS + Android（一套代码） |
| 框架 | Expo（最新稳定 SDK）+ React Native + TypeScript |
| 路由 | expo-router（文件路由，底部 Tab Layout） |
| 状态管理 | Zustand |

## 3. 数据模型

模板（用户编辑的结构）与记录（每次检查的结果）分离：修改模板不影响已生成的历史。

| created_at | int | 毫秒时间戳 |

**Group（分组）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | uuid |
| checklist_id | text fk | 所属检查单 |
| title | text | 分组名 |
| sort_order | int | 组内排序 |

**Item（检查项模板）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | uuid |
| group_id | text fk | 所属分组 |
| title | text | 检查项标题 |

### 3.2 实例与记录表

**Occurrence（某次检查实例）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | uuid |
| checklist_id | text fk | 来源检查单 |
| due_date | text | 应完成日期，本地时区 `YYYY-MM-DD` |
| status | text | `active` / `done`；由结果实时推导，无勾选项时为 active |
| completed_at | int/null | 全部项完成的时间戳；取消勾选时清空 |
| created_at | int | 实例生成时间 |

Occurrence 生成时同时固化该次的**标题快照**：

**OccurrenceItem（实例检查项快照）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | uuid |
| occurrence_id | text fk | 所属实例 |
| source_item_id | text | 来源模板项 id（可为已删除项保留） |
| group_title | text | 生成时的分组标题快照 |
| group_sort_order | int | 快照 |
| item_title | text | 生成时的检查项标题快照 |
| sort_order | int | 快照 |

执行页按快照渲染（按 `group_title` + `group_sort_order` 分组展示），保证历史真实。

**ItemResult（勾选记录）**

| 字段 | 类型 | 说明 |
|---|---|---|
| occurrence_item_id | text pk/fk | 对应快照项 |
| done | int | 0/1 |
| toggled_at | int | 最近一次切换时间 |

**DateException（手动日期例外）**

| 字段 | 类型 | 说明 |
|---|---|---|
| id | text pk | uuid |
| checklist_id | text fk | 检查单 |
| date | text | `YYYY-MM-DD` |
| type | text | `exclude`（该天跳过）/ `include`（该天补一次） |
| created_at | int | |

唯一约束：`(checklist_id, date)`。

## 4. 重复规则与实例生成

### 4.1 周期定义

- `none`：仅生成一次（创建当天），完成后不再出现
- `daily`：每天
- `weekly`：仅 `weekdays` 中选中的星期（1=周一 … 7=周日）
- `workdays`：周一至周五（不含法定节假日逻辑）

### 4.2 例外叠加

对某检查单、某日期 d：

1. 按周期规则判断 d 是否"应有"实例
2. 若存在 `exclude` 例外：不生成（即使周期命中，如国庆假期中的工作日）
3. 若存在 `include` 例外：生成（即使周期未命中，如调休上班的周末）

用户通过日历页**长按某天**或模板设置中的"例外日期"入口，为某个检查单标记"该天跳过 / 该天补做"。

### 4.3 生成策略

- **懒生成**：App 启动 / 回到前台 / 进入今日页时，确保每个未归档检查单从今天起未来 30 天的实例存在；并回填今天（若缺失）
- 不预生成久远历史；历史页查看某天时若该天在今天之前则按当时规则即时补算（只读）
- 所有日期以**设备本地时区的自然日**为准，dueDate 是纯日期字符串，不存时分秒，避免跨时区问题
- 空检查单（0 个检查项）不生成实例、不计入今日

### 4.4 模板变更对实例的影响

- 修改标题 / 图标 / 颜色：立即反映在所有页面（不影响历史快照项内容，只影响检查单级展示；历史执行页标题也用当前模板标题）
- 修改重复规则：删除**未来且无任何勾选**的实例后按新规则重建；已有勾选的未来实例保留
- 新增 / 编辑 / 删除 / 排序 分组或检查项：同上，仅影响"未来且无勾选"的实例；已有勾选的实例保留旧快照
- 删除检查单：二次确认，删除模板及全部实例/结果；归档仅从今日隐藏

## 5. 完成规则

- 勾选操作**即时写库**（乐观更新，无"保存"按钮），写入 ItemResult
- Occurrence.status 与 completed_at **由结果实时推导**，不手工维护：
  - 全部 OccurrenceItem 都存在 done=1 的 ItemResult → status=done，completedAt=最后一项勾选时间
  - 任意一项取消 → status=active，completedAt=null
- 点击勾选圆钮带轻微触感反馈；勾完最后一项触发轻量庆祝反馈（勾选动画 + 触感，不做全屏弹层）
- 今日页卡片可直接点圆钮快速勾选该检查单的"下一个未完成项"（见 6.1），点卡片其他区域进入执行页

## 6. 页面设计（4 Tab）

> 单手操作原则：列表内勾选圆钮统一放在每行**最右侧**，直径 ≥ 20px（建议 24px 触控热区 ≥44px）。拖拽排序手柄在圆钮左侧。新增按钮放在内容区底部，拇指可及。

### 6.1 今日（首页 Tab 1）

- 顶部：当天日期、星期、问候语；当日汇总（如"今日 1/3 已完成"）、连续完成天数
- 检查单卡片列表：
  - 左侧：图标 + 标题；右侧：进度文本（2/5）+ 勾选圆钮
  - 卡片内细进度条；状态：未开始 / 进行中 / 已完成
  - 点圆钮 = 勾选下一个未完成项（快捷操作）；点其他区域 = 进入执行页
  - 排序：进行中/未开始在前，已完成沉底（带置灰 + 打勾样式）
- 空状态：引导创建第一个检查单（跳转模板 Tab）
- 当天无任何到期实例（如全部设为例外）：显示"今天没有检查安排"

### 6.2 执行页（从今日/历史进入）

- 顶部导航：检查单标题 + 日期（历史进入时显示日期且**只读**，无勾选钮）
- 大进度环：已勾/总数 + 百分比
- 分组折叠列表：
  - 组头：组名 + 组进度（2/3）+ 折叠箭头，默认全部展开
  - 检查项行：左侧文本，右侧拖拽手柄（仅模板编辑用，执行页不显示）+ **右侧勾选圆钮**
  - 已勾选项标题加删除线、置灰
- 最后一项勾完：圆钮勾选动画 + 触感，进度环到 100%

### 6.3 日历（Tab 2）

- 顶部统计：当前连续完成天数、近 30 天完成率
- 月历：
  - 每天可有多检查单，聚合为一个状态点：
    - 绿 = 当天所有到期实例完成
    - 橙 = 部分完成
    - 灰 = 有到期实例但均未完成
    - 无点 = 当天无任何安排
  - 今天高亮描边
- 点选某天：下方列出当天各检查单及完成情况，点入执行页只读回看
- **长按某天**：弹出例外标记菜单（选择检查单 → 该天跳过 / 补做 / 取消例外），被标记的日期在日历上显示小标记

### 6.4 模板（Tab 3）

- 检查单列表（活跃 + 归档分区），每项：图标、标题、重复规则摘要、项总数；右上/行尾编辑入口；底部"+ 新建检查单"
- **模板编辑页**：
  - 标题输入、图标选择、颜色选择
  - 重复周期：不重复 / 每天 / 每周（多选星期）/ 工作日；下方"例外日期"管理入口
  - 分组卡片：组标题可改；组内检查项列表，可增、改文字、滑动删除、长按拖拽排序；每组底部"＋ 添加检查项"
  - 卡片底部"＋ 添加分组"；分组可拖拽排序、删除（删组需确认，连同其检查项）
  - 底部"删除检查单 / 归档检查单"

### 6.5 设置（Tab 4）

- 数据导出：导出全量数据为 JSON 文件（系统分享/保存）
- 数据导入：第一版不做（后续版本再加，导入时二次确认覆盖）
- 通知：开关项（置灰，标注"即将推出"）
- 关于：版本号

## 7. 架构与代码组织

分层，每层单一职责、可独立测试：

```
app/                    # expo-router 路由
  (tabs)/index.tsx      # 今日
  (tabs)/calendar.tsx   # 日历
  (tabs)/templates.tsx  # 模板列表
  (tabs)/settings.tsx   # 设置
  checklist/[id].tsx    # 执行页（query: occurrenceId / date）
  template/[id].tsx     # 模板编辑
src/
  db/
    schema.ts           # Drizzle 表定义
    client.ts           # sqlite 打开、迁移执行
    migrations/         # drizzle-kit 生成
  repositories/         # 仓储：checklist / occurrence / result 等，统一 try/catch
  services/
    recurrence.ts       # 纯函数：周期命中、日期序列
    occurrence-generator.ts  # 懒生成、回填、重建
    progress.ts         # 完成推导、连续天数、完成率
  stores/               # zustand：今日数据、日历数据等薄 store
  features/             # 按功能聚合的组件与 hooks（today/checklist/calendar/template）
  components/           # 通用 UI（Checkbox、ProgressBar、Ring、Calendar...）
  utils/date.ts         # 本地日期工具（parse/format/weekday/范围遍历）
```

- UI 只通过 stores/hooks 调 repositories；repositories 返回普通对象，不向上抛 DB 异常，失败统一 Toast 提示
- 所有业务规则（recurrence、progress、snapshot）写成**不依赖 React 和 DB 的纯函数**，优先被单测覆盖

## 8. 错误处理

- DB 打开/迁移失败：显示错误屏（"数据库初始化失败，可导出诊断信息"），不白屏
- 写操作失败：Toast 提示"操作失败，请重试"，UI 回滚乐观状态
- 导出失败：允许重试；分享面板取消不算错误
- 所有仓储方法捕获异常并经统一日志通道记录（第一版 console + 可选写本地日志表）

## 9. 测试策略

### 9.1 单元测试（Vitest，纯函数优先）

- `recurrence`：
  - daily / none 边界
  - weekly 选中星期、跨月跨年
  - workdays 跨周末
  - include/exclude 例外叠加、重复例外幂等
- `occurrence-generator`：
  - 懒生成窗口（30 天）、重复执行不重复创建
  - 回填今天、空检查单不生成
  - 规则变更后：无勾选未来实例被重建、有勾选保留
- `progress`：全勾→done 与 completedAt；取消→active；连续天数在中断后归零；完成率统计
- `snapshot`：生成时固化标题；删除模板项后历史仍可渲染（显示"已删除项"场景不出现，因为快照保留旧标题）

### 9.2 仓储集成测试

- expo-sqlite 临时库上跑 CRUD、级联删除、唯一约束、迁移

### 9.3 组件/交互测试（RNTL）

- 执行页：点右侧圆钮 → 勾选、进度更新；勾完最后一项 → done
- 今日页：快捷勾选推进"下一个未完成项"；完成卡片沉底
- 模板编辑：新增组/项、排序后新建实例使用新结构

### 9.4 手动验收清单

- iOS 模拟器与 Android 模拟器各一遍：建单→分组→检查项→今天勾选完成→日历回看→改规则验证未来实例→例外日期→杀进程重开数据不丢→导出 JSON

## 10. 验收标准（第一版）

1. 能完成检查单/分组/检查项的增删改与拖拽排序
2. 四种重复周期正确生成实例；工作日跳过周末；例外日期生效
3. 勾选实时保存、进度实时推导；全勾自动完成，可取消
4. 日历可回看任意一天；连续天数、30 天完成率正确
5. 历史记录不被模板编辑破坏（快照）
6. 重启 App 数据完整；可导出 JSON 备份
7. 勾选操作目标位于行右侧，单手可达；iOS/Android 主流程通过手动验收
